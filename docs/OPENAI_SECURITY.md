# Безопасность OpenAI API key

`OPENAI_API_KEY` является серверным секретом. PRICE читает его только из переменных окружения. Ключ не должен попадать в GitHub, Telegram-сообщения или логи.

AI-слой использует `store=False` для запросов нормализации товара и не передаёт в модель BOT_TOKEN, платёжные идентификаторы, cookies или содержимое базы данных.
