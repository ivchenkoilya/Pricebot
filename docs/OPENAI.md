# OpenAI в PRICE

OpenAI — опциональный слой. Без API-ключа PRICE продолжает работать: ссылки, providers, история цен, scheduler и уведомления не зависят от AI.

## Amvera

Добавьте секрет:

- `OPENAI_API_KEY` — API key OpenAI Platform.

Не добавляйте настоящий ключ в GitHub, `.env.example`, README или сообщения Telegram.

Дополнительные переменные:

- `AI_ENABLED=true`
- `OPENAI_MODEL=gpt-5-mini`
- `OPENAI_TIMEOUT=15`
- `OPENAI_MAX_OUTPUT_TOKENS=300`

После изменения secrets перезапустите приложение.

## Проверка с телефона

1. В Telegram отправьте `/ai_status`.
2. Ожидается `AI: ON` и имя модели.
3. Отправьте обычным текстом: `айфон 16 про 256 чёрный`.
4. PRICE должен нормализовать название товара, но не придумывать цену.
5. После этого отправьте ссылку на карточку товара — реальную цену получает provider магазина.

AI не используется для генерации или угадывания цен.
